# Tabrej Siddiqui — Portfolio

A modern, responsive portfolio website created from the information in the supplied resume.

## Included
- `index.html` — portfolio content
- `style.css` — responsive dark UI
- `script.js` — mobile menu + active navigation
- `profile.jpg` — profile image
- `Tabrej_Siddiqui_Resume.pdf` — resume

## Run locally
Open `index.html` in a browser.

For VS Code:
1. Open the `tabrej-portfolio` folder.
2. Install/use Live Server.
3. Right-click `index.html` → **Open with Live Server**.

## Deploy
The folder can be deployed to Vercel, Netlify or GitHub Pages as a static site.
